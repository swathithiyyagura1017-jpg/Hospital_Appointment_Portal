# Hospital Appointment Portal

## About the Project
The Hospital Appointment Portal is a web application developed using Django.
It helps patients book appointments with doctors and allows hospital staff
to manage appointments.

## Technologies Used
- Python
- Django
- HTML
- CSS
- Bootstrap 5
- SQLite

## Features
- Patient registration and login
- Doctor and department details
- Online appointment booking
- Appointment status tracking
- Staff login and dashboard
- Medical report management

## Installation and Setup

1. Clone the repository.
2. Open the project folder.
3. Create and activate a Python virtual environment.
4. Install dependencies:

   pip install -r requirements.txt

5. Run database migrations:

   python manage.py migrate

6. Start the development server:

   python manage.py runserver

7. Open http://127.0.0.1:8000/ in your browser.
